# Runtime-authority exceptions: path<TAB>rule<TAB>detail<TAB>count.

# Every production `std::env::var*` read, `which::which` call, direct
# `Command::new`, and `set_current_dir` outside test-only regions must be
# listed here with a reason, or scripts/check-runtime-authority.py fails.
# Runtime shell consumers (prompt, doctor, editors, Lisp, palette, external
# dispatch) resolve through CommandRuntimeSnapshot instead and must never
# appear here. A `#` comment above each entry group explains why the
# process-global read is the authority there; adding a new same-shape call
# changes the count and fails until a human reviews it. Removing a site
# without dropping its entry fails as stale.
#
# Rules: process-env | which | command | set-cwd
